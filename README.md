# OpenAPI SDK MCA

MCA OpenAPI SDK for Zerofinance.

## Requirements

- JDK 8 or newer
- Maven 3.9 or newer

## Dependency

```xml
<dependency>
    <groupId>com.zerofinance</groupId>
    <artifactId>openapi-sdk-mca</artifactId>
    <version>1.0.1</version>
</dependency>
```

## Build

```bash
mvn clean verify
```
